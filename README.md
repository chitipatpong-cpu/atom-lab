# Atom Lab · ห้องทดลองโมเลกุล

เว็บจำลองการสร้างโมเลกุล — ลากอะตอมมาต่อกันเพื่อสร้างสาร ดูรูปร่าง 3 มิติ (VSEPR) สภาพขั้ว และทำปฏิกิริยาเคมี

**หน้าในเว็บ:** ห้องทดลอง · ตารางธาตุ 118 ธาตุ · ปฏิกิริยาเคมี · การสลายตัวของธาตุ · ความรู้เคมี · เครื่องมือคำนวณ

## เปิดใช้งาน
เว็บแบบ static ไม่ต้องติดตั้งอะไร — เปิด `index.html` ในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Three.js และฟอนต์)

## โครงสร้างไฟล์
| โฟลเดอร์/ไฟล์ | เนื้อหา |
|---|---|
| `js/elements.js` | ข้อมูลธาตุ 118 ธาตุ (สร้างจาก PubChem + CIAAW) |
| `js/data/compounds/` | สารประกอบ แยกไฟล์ตามหมวด |
| `js/data/reactions/` | ปฏิกิริยาเคมี แยกไฟล์ตามประเภท |
| `js/data/isotopes.js` | ไอโซโทปกัมมันตรังสี |
| `js/compound-refs.js` | PubChem CID, จุดหลอมเหลว/จุดเดือดของสารประกอบ |
| `js/learn/` | หน้าความรู้เคมี 1 หัวข้อต่อ 1 ไฟล์ |
| `js/tools/` | เครื่องมือคำนวณ 1 เครื่องมือต่อ 1 ไฟล์ |
| `css/` | สไตล์ |

แหล่งอ้างอิงข้อมูลทั้งหมดอยู่ในหน้า **ความรู้เคมี → แหล่งอ้างอิงข้อมูล**
